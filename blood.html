আপনি কী করতে চান?

নিচের যেকোনো একটি অপশন নির্বাচন করুন

রক্তদাতা খুঁজুন রক্তের গ্রুপ, জেলা ও উপজেলা নির্বাচন করে সার্চ দিন

রক্তদাতা হিসেবে যোগ দিন নতুন রেজিস্ট্রেশন করুন অথবা আগের User ID দিয়ে তথ্য আপডেট করুন

🔑 আগে রেজিস্ট্রেশন করেছেন?
আপনার আগের User ID বসিয়ে তথ্য আনুন বাটনে ক্লিক করুন — তারপর শুধু তারিখ পরিবর্তন করে সেভ করুন।
অথবা নিচের ফর্ম পূরণ করে নতুন রেজিস্ট্রেশন করুন 👇
ℹ️ নতুন রেজিস্ট্রেশনে অটো তৈরি হবে। আপডেটের জন্য উপরের ফিল্ড ব্যবহার করুন।
গুরুত্বপূর্ণ নির্দেশনা
  1. সম্পূর্ণ তথ্য সঠিক ভাবে লিখুন।
  2. পরবর্তী তে আপনার কোনো তথ্য বা শেষ বার রক্ত দেওয়ার তারিখ পরিবর্তন করতে ইউজার আইডি সংগ্রহ করুন।
  3. তথ্য আপডেট করবেন যেভাবে — উপরে আপনার ইউজার আইডি বসিয়ে তথ্য আনুন বাটনে চাপুন আপনার সব তথ্য চলে আসবে। এরপর তথ্য পরিবর্তন করে রেজিস্ট্রার বাটনে চাপুন।
  4. ইউজার আইডি ভুলে গেলে অ্যাডমিন এর ফেসবুক পেইজে মেসেজ করুন।
